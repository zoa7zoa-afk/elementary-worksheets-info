개인정보처리방침

이 도구는 사용자의 Google OAuth 동의를 받아 Google Drive에 접근합니다. 인증 과정에서 계정 이메일과 대상 폴더의 접근 권한을 확인하고, 실행 과정에서 대상 폴더의 파일 이름·ID를 조회하며 교재 파일을 생성하거나 명시적으로 지정된 파일을 갱신합니다. 현재 요청 범위는 전체 Drive 접근 권한이지만, 프로그램의 정상 동작은 지정 폴더와 그 주차별 하위 폴더로 제한합니다. 인증 토큰과 클라이언트 설정은 로컬 비공개 설정 파일에 보관하며, 향후 예약 실행을 설정할 경우 운영자가 선택한 실행 환경의 비밀 저장소에도 보관할 수 있습니다. 이 도구는 Google Drive의 문서 내용을 LLM 제공자에게 보내지 않습니다. 공개 기사와 생성된 교재는 설정한 LLM 제공자에게 생성·검수 목적으로 전송합니다. Google 사용자 데이터는 광고·판매 목적으로 사용하지 않습니다. Google 계정의 타사 앱 연결에서 권한을 철회할 수 있으며 운영 환경의 인증 파일·비밀 설정도 삭제할 수 있습니다. 문의: GitHub 저장소 zoa7zoa-afk/elementary-worksheets-info의 Issues를 이용해 주세요. 시행일: 2026년 10월 27일.
